# Telco Customer Churn Prediction

Predicting customer churn for a telecom company using classical ML.

## Goal
Identify customers likely to churn so the business can target retention efforts.

## Data
Telco Customer Churn dataset (Kaggle) — 7,043 customers, mix of demographic,
account, and service usage features.

## Status
🚧 In progress — EDA phase

## Approach
- Exploratory data analysis
- Feature engineering
- Model comparison (Logistic Regression, Random Forest, XGBoost)
- Evaluation focused on precision/recall due to class imbalance
